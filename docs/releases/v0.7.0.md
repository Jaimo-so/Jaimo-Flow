# Jaimo Flow 0.7.0 · 顶部刘海与悬停工具站

## 顶部刘海入口

- 在内置屏幕顶部、菜单栏中央显示黑色刘海；没有内置屏幕时使用主屏幕，支持 MacBook Air M1 等无物理刘海的机型。
- 鼠标移入并停留 120ms 展开工具站；移出刘海和内容区 300ms 后收起。快速划过不会立即展开，短暂移出后返回会取消收起，进入内容区可继续操作。
- 展开使用 280ms 淡入、轻微缩放及位移，收起使用 200ms 反向动效；系统开启“减弱动态效果”时取消窗口缩放和位移。
- 移除原菜单栏图标和侧边悬浮球，顶部刘海成为唯一常驻可视入口；全局快捷键 `⌥Space` 继续显示或隐藏完整工具站。
- 刘海支持拖入文件或文件夹，创建独立本地副本并打开文件中转站；右键菜单可打开工具站、中转站、偏好设置、隐藏刘海或退出应用。
- 设置、确认浮层、窗口缩放及拖动期间暂缓自动收起。主动关闭后，指针需移出刘海再移回，才会再次展开；快速收起后重新打开不会被旧动画关闭。
- 展开动效保留工作区布局和已保存的窗口尺寸，适配屏幕时不覆盖用户的尺寸偏好。

## Vibehub 话术库与整理 Agent

- 新增独立的 Vibe Coding 话术库，以笔记形式保存标题、完整话术原文、用途分类、标签、适用场景及术语与含义；支持搜索、收藏、完整复制和自动保存。
- 用途分类包括路由与导航、界面与布局、交互与动效、数据与接口、调试与测试、部署与工程、未分类。可按本地关键词识别或手动选择，后续编辑原文不会覆盖手动分类。
- 首次打开内置“页面切换与哈希路由”示例，保留完整原文、适用场景、术语定义及意义；删除后不会在重启时重新添加。
- Agent 支持自行配置 OpenAI 兼容的 Chat Completions 接口、模型、API Key 和 JSON 模式，API Key 保存在本机 macOS 钥匙串中。
- 整理原样保留用户输入的原文，包括空格、换行和段落；补全结果先进入可编辑预览，只有手动确认才保存到话术库。完整原文、适用场景、定义和意义分别保存，长文可以滚动查看，不折叠或删减知识点。
- 未确认输入和预览不保存草稿；关闭话术面板、隐藏窗口或取消整理会清空，重新打开从空白输入开始。调用失败可保留输入重试，本地保存失败保留可编辑预览且不会重复创建记录。
- 只有主动点击“整理并预览”时，当前输入和整理规则才会发送到用户配置的模型服务，完整话术库、剪切板历史和备忘录不会附带发送。

## 每日复盘与笔记保存

- 新增每日复盘组件，按日期填写、编辑和保存当日复盘内容，支持查看历史复盘并选择复制正文。
- 快速便签与备忘录在输入、停顿及切换记录期间保留内存修改，在关闭编辑界面、离开首页、隐藏工具站或正常退出时保存最新完整内容；保存失败时保留内容并允许重试。
- 改进备忘录新建与重复调用的稳定性，保持便签和备忘录连续输入、中文输入法组合文本与光标位置。
- 提示词编辑期间点击应用外部可以收起窗口，重新打开仍保留未保存的编辑内容。

## 下载与升级

- 支持 macOS 13 及以上，仅提供 Apple Silicon 安装包，不提供 Intel 版本。
- 下载附件 `Jaimo-Flow-0.7.0-macOS-Apple-Silicon.dmg`，将 `Jaimo Flow.app` 拖入 `Applications`。
- 旧版用户可在应用偏好设置中选择“检查更新”，发现 0.7.0 后使用一键更新；新版刘海右键菜单可打开偏好设置。
- 安装包保留旧版更新器所需的应用名称兼容入口，继续使用现有应用标识和本地数据目录。
- 同时提供 `.sha256` 校验文件。将两个附件下载到同一目录后运行：

```sh
shasum -a 256 -c Jaimo-Flow-0.7.0-macOS-Apple-Silicon.dmg.sha256
```

安装包沿用临时代码签名，未进行 Apple Developer ID 公证。
