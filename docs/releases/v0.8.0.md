# Jaimo Flow 0.8.0 · 内置终端

## 内置终端

- 工具站顶部新增「终端」入口，可在应用内使用交互式 shell 执行命令。
- 切换到其他页面后，终端会话和屏幕输出会保留；返回终端即可继续操作。
- 点击「关闭终端」结束当前 shell 会话；点击「重新打开终端」启动新会话。关闭会结束当前会话及其终端交互，请先处理正在运行的任务。
- 支持终端尺寸调整和终端程序所需的键盘输入。

## 下载与升级

- 支持 macOS 13 及以上，仅提供 Apple Silicon 安装包，不提供 Intel 版本。
- 下载 `Jaimo-Flow-0.8.0-macOS-Apple-Silicon.dmg`，将 `Jaimo Flow.app` 拖入 `Applications`；现有本地数据会保留。
- 已安装的用户也可在应用偏好设置中检查更新。
- 下载同目录中的 `.sha256` 文件后，可在终端运行以下命令校验安装包：

```sh
shasum -a 256 -c Jaimo-Flow-0.8.0-macOS-Apple-Silicon.dmg.sha256
```

安装包沿用临时代码签名，未进行 Apple Developer ID 公证。
