# Jaimo Flow 0.13.0 · 账号额度监控与导航栏自定义

## 账号额度监控

- 新增「额度」页面（`⌘7`），采用瀑布流多列卡片布局集中查看多个 AI 编程与模型账号的剩余额度与余额，覆盖 **Codex CLI**、**Antigravity CLI**、**Gemini CLI** 与 **DeepSeek** 四类供应商。
- 默认内置「本机 Codex」和「本机 Antigravity」两个账号，支持按需添加多个账号配置，可自定义配置目录（`CODEX_HOME` / `HOME`）、CLI 可执行文件路径与套餐标签，并提供「恢复本机账号」入口。
- **Gemini CLI** 默认支持「Google 网页登录」，自动读取本机 `gemini` CLI 或 `GEMINI_OAUTH_CLIENT_ID` / `GEMINI_OAUTH_CLIENT_SECRET` 环境变量中的 OAuth 客户端配置，通过 PKCE 与本机 `127.0.0.1` 回环回调在默认浏览器完成 Google OAuth 授权，令牌加密保存于独立 macOS 钥匙串服务 `com.clipflow.mac.quota` 并自动刷新；也可切换为「本机 CLI 凭证」（读取 `~/.gemini/oauth_creds.json` 或自定义凭证路径）。
- **DeepSeek** 支持通过保存于独立钥匙串服务 `com.clipflow.mac.quota` 的 API Key 查询 `/user/balance` 多币种可用总额与充值/赠金明细，支持自定义接口地址（远程地址须为 HTTPS，本机服务可用 HTTP），移除账号时同步清理对应密钥。
- 卡片展示各额度桶剩余百分比、重置倒计时与历史趋势折线（60 秒内且变化不足 0.05 个百分点的样本自动合并，每个额度桶保留最近 96 点），突出显示账号邮箱，并内置五张随外观切换的品牌图标。
- 首次进入额度页、重新展开窗口、切回额度页或退出设置回到额度页时自动检查并刷新过期（超过 5 分钟）或本次会话尚未查询的账号；支持 `⌘R` 刷新全部、单账号并发刷新与请求取消，失败时保留上次成功快照。非敏感账号配置、快照与历史记录保存于本机 `Quota/state.json`。

## 导航栏与页面自定义

- 将设置中的模块控制升级为「导航栏与页面」与「首页模块」两组，全部页面默认开启，至少保留一个启用页面。
- 「导航栏与页面」支持独立开关首页、应用、提示词、剪切板、Vibehub、终端与额度七个页面，隐藏入口的同时停用对应 `⌘1`–`⌘7` 快捷键；当前页或启动恢复页被关闭时无动画切回首个启用页，关闭终端或额度时同步释放会话或停止查询并保留本地数据。
- 支持选择「图标 + 名称」或「仅图标」导航显示方式（窄窗口自动折叠名称，悬停显示名称与快捷键），并提供「恢复默认」一键还原。
- 「首页模块」独立控制录音与转写和镜子，开关行为与本地数据保留策略保持一致。

## 界面与自检

- 优化顶部导航胶囊在不同启用页面数量下的宽度折叠阈值，并将 Vibehub 标题栏调整为更紧凑的布局。
- 新增 `./Scripts/run-quota-self-test.sh` 账号额度自检，全部开发期自检扩展至八项（`./Scripts/run-all-self-tests.sh`）；扩展面板自检，覆盖导航栏页面开关、显示方式、恢复默认、按需加载、额度过期刷新与查询取消。

## 下载与升级

- 支持 macOS 13 及以上，仅提供 Apple Silicon 安装包。识别与翻译扩展需要 macOS 15 或更高版本。
- 下载 `Jaimo-Flow-0.13.0-macOS-Apple-Silicon.dmg`，将 `Jaimo Flow.app` 拖入 `Applications`。升级会保留现有本地数据。已安装的用户也可在应用偏好设置中检查更新。
- 将配套的 `.sha256` 文件与 DMG 放在同一目录，然后在终端校验安装包。

```sh
shasum -a 256 -c Jaimo-Flow-0.13.0-macOS-Apple-Silicon.dmg.sha256
```

安装包沿用临时代码签名，未进行 Apple Developer ID 公证。

完整源码变更见 [v0.12.0...v0.13.0](https://github.com/Jaimo-so/Jaimo-Flow/compare/v0.12.0...v0.13.0)。
