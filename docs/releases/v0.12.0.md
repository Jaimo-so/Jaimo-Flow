# Jaimo Flow 0.12.0 · 模块开关与性能优化

## 模块开关

- 在「偏好设置 → 模块」中可以独立开关内置终端、录音与转写、镜子。三个模块默认开启，设置即时生效并保存在本机。
- 关闭内置终端会隐藏导航入口并停用 `⌘6`。当前页面或启动时准备恢复的页面为终端时，工具站会无动画返回首页并记住该页面。关闭时结束当前 shell 会话并释放 WebView，重新开启后首次进入终端页才初始化终端。
- 关闭录音与转写会结束并保存正在录制或暂停的录音，关闭转写工作台、取消转写并释放播放器和转写管理器。这次保存的录音可在重新开启后手动转写。已有录音、字幕和服务配置均保留。
- 关闭镜子会立即停止预览、释放摄像头并隐藏偏好设置中的「首页照片」。本地封面会保留，重新开启后可手动启动摄像头。
- 录音和镜子关闭时，对应组件会从首页及「已隐藏」恢复入口移除。模块设置与首页布局偏好独立保存，重新开启后恢复原有的显示或隐藏状态。

## 启动与常驻性能

- 首次进入终端页时才创建终端会话对象和 WebView，之后可在切页时保留会话。录音转写管理器在打开工作台或录音结束且已配置自动转写时才创建。
- 应用目录只在打开的工具站显示「应用」页，或首页显示「最近使用」组件时加载。直接打开偏好设置时，也会将终端初始化和应用目录加载推迟到对应页面出现时。
- 工具站只在展开期间安装用于外部点击、指针跟踪和快捷键的面板监听，收起后卸载。顶部刘海只在处理文件拖拽及松开时检查拖拽剪贴板，普通指针移动沿用指针事件路径。镜子封面仅在载入或更换时读取照片方向，布局直接使用已有结果。
- 剪切板新增记录与淘汰历史在同一个 SQLite 事务中完成。列表根据实际写入的记录和被淘汰的条目增量更新，并同步选中状态。连续相同内容仍按 SHA-256 去重，保留最近 150 条非收藏项，收藏项额外保留。

## 提示词与 Vibehub

- 「提示词」是通用模板库。模板支持分组、搜索、收藏、变量填写和使用次数记录，可用 `{{变量}}` 标记每次调用时填写的内容。可从剪切板历史保存为提示词，保存成功后直接进入提示词页。
- Vibehub 是面向 Vibe Coding 的编程话术与术语知识库，保存完整话术原文、标签、适用场景、术语定义和含义。配置模型后可由 Agent 辅助分类和补全，预览可逐项编辑，手动确认后才写入话术库。

## 外观与导航

- 主窗口、文件中转小兜和内置终端同步响应外观设置。终端随浅色与深色外观调整文字、背景和光标颜色，切换外观时保留当前会话。
- 使用鼠标或快捷键切换页面时，选中状态与页面内容同步更新。顶部导航在较窄的窗口中显示图标，并保留提示和辅助功能标签。

## 架构与自检

- 应用源码按功能组织。剪切板历史、提示词与 API Key 分组各自管理列表和编辑状态，剪切板的增量更新只通知对应资料库。资料库页面共用搜索、分类和弹层组件，备忘录、每日复盘、Vibehub 与文件中转索引共用 JSON 文件读写逻辑，已有本地数据路径和格式保持兼容。
- 新增 `./Scripts/run-all-self-tests.sh`，一次构建调试应用后依次运行七项自检。扩展面板与核心自检，覆盖模块偏好持久化、终端导航回落及资源释放、录音和镜子组件恢复、按需加载、监听生命周期、资料库快捷键和剪切板增量一致性。

## 下载与升级

- 支持 macOS 13 及以上，仅提供 Apple Silicon 安装包。识别与翻译扩展需要 macOS 15 或更高版本。
- 下载 `Jaimo-Flow-0.12.0-macOS-Apple-Silicon.dmg`，将 `Jaimo Flow.app` 拖入 `Applications`。升级会保留现有本地数据。已安装的用户也可在应用偏好设置中检查更新。
- 将配套的 `.sha256` 文件与 DMG 放在同一目录，然后在终端校验安装包。

```sh
shasum -a 256 -c Jaimo-Flow-0.12.0-macOS-Apple-Silicon.dmg.sha256
```

安装包沿用临时代码签名，未进行 Apple Developer ID 公证。

完整源码变更见 [v0.11.0...v0.12.0](https://github.com/Jaimo-so/Jaimo-Flow/compare/v0.11.0...v0.12.0)。
