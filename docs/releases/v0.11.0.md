# Jaimo Flow 0.11.0 · 文件中转小兜

## 文件中转小兜

- 文件中转面板改为贴合刘海下沿居中悬垂的小兜，使用紧凑的弧形轮廓；背景与前景跟随 Jaimo Flow 外观设置，包括跟随系统浅色、深色以及黑色主题。拖入时轮廓高亮，提示可放置文件。
- 将本地文件或文件夹拖近刘海时，小兜自动张开；松手后将每项保存为独立的本地副本，拖离则收起。小兜打开时仍可继续添加文件。连续导入会排队串行处理；单项导入失败不会中断其他项目，并会显示错误信息。
- 小兜只展示文件图标或缩略图和文件名。文件可直接拖出，双击可快速预览；右键菜单提供预览、复制文件、在访达中显示、移除和清空操作。拖出后默认保留小兜中的副本；启用 `fileRelay.removeAfterDrag` 偏好时，仅成功拖出的项目会被移除。
- 文件中转索引和副本继续保存在本机 `~/Library/Application Support/ClipFlow/FileRelay/`。每个项目都有自己的副本，原文件后续变化不会改变已保存的中转文件。

## 刘海与交互改进

- 有物理刘海的屏幕会避开摄像头区域并在两侧留出空间：左侧显示品牌图标，右侧在空状态显示展开箭头，有文件时显示文件数量徽标。无物理刘海的屏幕继续显示品牌图标、名称和展开箭头，有文件时增加徽标。
- 悬停刘海主体可打开工具站；有文件时悬停或点击右侧徽标可打开小兜。刘海右键菜单也可打开小兜，并提供清空文件中转的入口。
- 小兜和工具站互斥。鼠标移出入口和内容区域后会延迟收起，快速返回可取消收起；固定、拖出或菜单操作期间暂缓自动收起。按 Escape 可关闭小兜；未固定时点击外部也可关闭。
- 改进文件拖拽状态识别，排除拖拽剪贴板中残留的旧文件地址和非文件拖拽，并在拖出期间禁用拖入识别，避免误打开小兜或重复接收文件。
- 扩展面板自检，覆盖物理刘海与无刘海屏幕的几何、文件导入和本地副本、徽标入口、拖拽状态、固定和收起行为。

## 下载与升级

- 支持 macOS 13 及以上，仅提供 Apple Silicon 安装包；识别与翻译扩展需要 macOS 15 或更高版本。
- 下载 `Jaimo-Flow-0.11.0-macOS-Apple-Silicon.dmg`，将 `Jaimo Flow.app` 拖入 `Applications`；现有本地数据会保留。已安装的用户也可在应用偏好设置中检查更新。
- 下载配套的 `.sha256` 文件后，可在终端校验安装包：

```sh
shasum -a 256 -c Jaimo-Flow-0.11.0-macOS-Apple-Silicon.dmg.sha256
```

安装包沿用临时代码签名，未进行 Apple Developer ID 公证。

完整源码变更：[v0.10.0...v0.11.0](https://github.com/Jaimo-so/Jaimo-Flow/compare/v0.10.0...v0.11.0)。
