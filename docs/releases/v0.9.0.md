# Jaimo Flow 0.9.0 · 黑色主题与截图扩展

## 黑色主题

- 在「偏好设置 → 通用 → 外观」中选择「黑色」或「跟随系统」；选择立即生效并保存在本机。
- 黑色主题使用近黑色背景和深灰色卡片，适合深色工作环境。

## 截图与贴图

- 在「偏好设置 → 扩展」中安装并启动截图与贴图；默认使用 `Control + Option + A` 截图，`Control + Option + P` 贴出剪贴板中的图片，快捷键可以在设置中修改。
- 截图支持调整选区、矩形、箭头、画笔、荧光笔、马赛克、文字、撤销和重做；可复制、贴图或另存为 PNG。放大镜显示像素和颜色，按 C 复制颜色，按 Shift 切换 RGB 和 HEX。
- 贴图支持拖动、双击关闭，以及通过右键菜单复制或关闭。扩展的运行状态和快捷键会在下次启动时恢复。
- 首次截图需要授予屏幕录制权限。此扩展随应用内置，暂不支持导入第三方扩展包。

## 识别与翻译

- 在「偏好设置 → 识别与翻译」中安装并启动，使用 `Control + Option + S` 框选截图并识别翻译；也可打开图片、读取剪贴板或直接输入文字。
- 支持选择目标语言、复制译文和查看本机历史记录。文字识别使用 macOS Vision，翻译使用系统翻译，要求 macOS 15 或更高版本；首次使用可能需要下载语言资源。

## 下载与升级

- 支持 macOS 13 及以上，仅提供 Apple Silicon 安装包；识别与翻译扩展需要 macOS 15 或更高版本。
- 下载 `Jaimo-Flow-0.9.0-macOS-Apple-Silicon.dmg`，将 `Jaimo Flow.app` 拖入 `Applications`；现有本地数据会保留。已安装的用户也可在应用偏好设置中检查更新。
- 下载配套的 `.sha256` 文件后，可在终端校验安装包：

```sh
shasum -a 256 -c Jaimo-Flow-0.9.0-macOS-Apple-Silicon.dmg.sha256
```

安装包沿用临时代码签名，未进行 Apple Developer ID 公证。
