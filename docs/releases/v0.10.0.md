# Jaimo Flow 0.10.0 · 录音转写工作台

## 录音转写升级

- 在首页录音组件打开“转写记录”，配置阿里云 Qwen3-ASR 或 OpenAI 兼容转写服务的接口地址、模型和 API Key。远程服务使用 HTTPS，本机服务可使用 HTTP；API Key 保存在本机 macOS 钥匙串。
- 自动转写默认开启，配置服务后每次录音完成会自动发送音频转写；也可在 ASR 设置中关闭自动转写，手动转写、重新转写或取消任务。
- 长录音按服务要求分段处理并合并结果。OpenAI 兼容接口支持 `diarized_json` 和 `verbose_json`，部分不支持的接口会回退普通 JSON；实际能力取决于服务和模型。

## 录音转写工作台

- 通义听悟风格的工作台以左侧录音列表和右侧演讲人、时间轴字幕呈现转写结果，支持搜索字幕、筛选演讲人、重命名演讲人、调整字幕归属与文字。
- 同步播放器支持播放、进度拖动和倍速；可复制含演讲人和时间戳的字幕、纯文本或 SRT 字幕。演讲人和时间戳取决于模型返回，纯文本结果的时间轴按文本比例估算。
- 可从列表右键菜单或详情区删除录音，二次确认后永久删除音频及关联 JSON、TXT 字幕；录制或暂停中的当前录音不可删除。
- 原始 M4A 和转写结果保存在本机；进行手动转写或启用自动转写后，音频或其分段会发送到用户配置的服务商。

## 下载与升级

- 支持 macOS 13 及以上，仅提供 Apple Silicon 安装包；识别与翻译扩展需要 macOS 15 或更高版本。
- 下载 `Jaimo-Flow-0.10.0-macOS-Apple-Silicon.dmg`，将 `Jaimo Flow.app` 拖入 `Applications`；现有本地数据会保留。已安装的用户也可在应用偏好设置中检查更新。
- 下载配套的 `.sha256` 文件后，可在终端校验安装包：

```sh
shasum -a 256 -c Jaimo-Flow-0.10.0-macOS-Apple-Silicon.dmg.sha256
```

安装包沿用临时代码签名，未进行 Apple Developer ID 公证。
